# huokaingthara_football_club_squad
⚽ Huokaing Thara Football Club (HTFC) Official Website

Welcome to the official web repository for Huokaing Thara Football Club (ក្លឹបបាល់ទាត់ ហួកាំង ថារ៉ា). This repository houses the source code for our official bilingual website, built to share club announcements, training updates, leadership news, player rosters, and recruitment information.

📌 Club Overview

"Health lives in peace, and sport is for health." — Official Motto

Founder & Interim Coach: Mr. Huokaing Thara (ហួកាំង ថារ៉ា)

Head Coach: Mr. Seng Chhat (សេង ឆាត) (Currently on medical recovery)

Target Roster: 22-Man Squad (Open to Male & Female candidates)

Training & Recruitment Base: Olympic Stadium, Phnom Penh (In front of the old court / ទល់មុខតុលាការចាស់)

Official Website: https://tharahuokaing.github.io/huokaingthara_football_club/

🌟 Key Features

🌐 Bilingual Support: Instant toggle between English and Khmer (ភាសាខ្មែរ) across all pages.

🏃‍♂️ Squad Roster & Coaching Showcase: Dedicated page (squad.html) featuring coaching staff details and player cards.

📱 Responsive Design: Dark-theme modern UI optimized for smartphones, tablets, and desktop displays.

⚡ Pure Web Stack: Built with pure HTML5, CSS3, and JavaScript — fast, lightweight, and dependency-free.

🏆 Leadership Updates: Clear announcements regarding coaching structure, training schedules, and team progress.

📁 Repository Structure

huokaingthara_football_club/
├── index.html     # Main Homepage (Hero banner, News, Coaching updates, Recruitment steps)
├── about.html     # About Us page (Vision, Motto, Leadership squad details)
├── squad.html     # Squad & Players page (Staff roles, 22-man roster showcase, recruitment slots)
├── style.css      # Dark-theme UI styles, modern layouts, and mobile responsiveness
├── script.js      # Language toggler (EN/KH) and interactivity logic
└── README.md      # Repository documentation


🚀 How to Run Locally

Clone the repository:

git clone https://github.com/tharahuokaing/huokaingthara_football_club.git


Navigate into the directory:

cd huokaingthara_football_club


Launch the website:
Open index.html, about.html, or squad.html directly in your favorite web browser.
